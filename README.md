
# DUOCAST

### TWO STREAMS. ONE PHONE.

DUOCAST is an experimental iOS audio player concept designed around two independent audio streams.

## Features
- Two independent audio players
- Separate volume controls
- Individual play and pause
- Stop both streams
- Premium black and grey interface

## Technology
- Swift
- SwiftUI
- AVFoundation

## Project Status
Early development.

## Important
Separate Bluetooth output routing is still under investigation.
